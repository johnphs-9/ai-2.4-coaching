# 2.4 Coaching Session: Number Guessing Game

## Session Overview

This coaching session gives learners unstructured time to apply the React concepts from Lessons 2.1 to 2.3 by building a small interactive app from scratch. The first 30 minutes are open Q&A on anything from the past three lessons. Learners then spend approximately two hours building a number guessing game independently, making their own decisions about component structure, state ownership, and data flow. The session closes with two learner presentations followed by an instructor walkthrough of a suggested solution.

## Dependencies

- [Activity Brief](./lesson.md)
- [Assignment](./assignment.md)

## Session Objectives

- Design a React component tree for a small interactive app without instructor-directed steps
- Apply `useState`, props, callbacks, and conditional rendering together in a single project built from scratch
- Derive display values from state instead of storing redundant copies in `useState`

## Session Plan

| Duration  | What                        | How or Why                                                                                              |
| --------- | --------------------------- | ------------------------------------------------------------------------------------------------------- |
| 30 min    | Q&A                         | Open floor for questions on Lessons 2.1–2.3; instructor addresses common misconceptions                 |
| 10 min    | Activity briefing           | Instructor reads through the requirements and hints; learners sketch a component plan before coding     |
| ~110 min  | Independent activity        | Learners build the number guessing game; instructor circulates and answers questions without giving solutions |
| 30 min    | Debrief                     | Two learners present their solutions; instructor walks through a suggested solution                      |
| **Total** |                             | **~180 min**                                                                                            |
